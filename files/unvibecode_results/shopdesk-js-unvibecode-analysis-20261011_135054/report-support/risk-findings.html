Business flaws

HIGH · STRONG EVIDENCE

1. Unauthenticated callers can export the complete order list

When an unauthenticated caller requests the order export path, the application skips authentication and returns every order as JSON.

Trigger

When an unauthenticated caller requests the order export path under the configured public prefix.

What the code does

The auth middleware skips session checks for paths starting with /api/orders/public, and the export handler returns db.allOrders() whenever request.user is absent.

Business rule

The complete order export is a privileged function and should not be available to unauthenticated public callers.

Basis: REPOSITORY ESTABLISHED

Business downside

Any public caller can retrieve every order through the export endpoint.

Impact

Immediate outcome
The complete order list is returned as JSON without authentication.
Affected party or asset
Order dataset
Scale mechanism
The handler returns db.allOrders(), so each successful request exposes the full order list rather than a single caller-scoped record.
Detection difficulty
Authenticated non-admin tests receive 403, which hides the public bypass unless the same path is tested without a session.
Reversibility
Access can be blocked after a code change, but data already returned to outside callers is not revoked.

How the code reaches the outcome

  • The application mounts authMiddleware before the admin routes.
  • authMiddleware immediately calls next() for any request whose path starts with a configured public prefix.
  • The configured public prefixes include /api/orders/public, and /api/orders/public-export matches that prefix.
  • The export handler only rejects callers when request.user exists and is not admin.
  • When request.user is absent, the handler returns db.allOrders() as JSON.

What to change

Require authenticated admin authorization before returning the full order export.

Acceptance check

Given An unauthenticated request targets the order export endpoint.
When The request is processed through middleware and the export handler.
Then The application denies the request instead of returning the full order list.
